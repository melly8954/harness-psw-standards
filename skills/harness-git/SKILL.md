# Harness Git

`../../standard_v0.md`의 `7. 커밋 작업 원칙`을 기준으로 한다.

## 수행

- 커밋 수행 권한, 메시지 형식, 커밋 단위, push·PR 정책의 근거를 확인한다.
- 기존 CONTRIBUTING, CI, 템플릿, Git 기록을 참고하되 관례를 정책으로 단정하지 않는다.

## 출력과 중단

확인된 Git 규칙과 근거를 출력한다. 명시 정책이 없으면 에이전트가 커밋·push·PR을 수행한다고 가정하지 않는다.
