# Harness Git

에이전트가 Git 커밋 작업까지 수행하는 프로젝트에만 커밋 관련 원칙을 정의한다. 수행하지 않는 프로젝트는 이 섹션을 생략할 수 있다.

## 포함할 수 있는 내용

- 에이전트의 커밋 수행 여부
- 커밋 단위와 메시지 규칙
- 관련 없는 변경 포함 금지
- 하나의 커밋에 서로 다른 목적의 변경을 혼합하지 않는 기준
- 자동 생성 문구 또는 특정 trailer 사용 여부
- push 수행 여부
- PR 생성 여부와 범위

커밋·브랜치·PR의 상세 협업 정책이 별도 문서에 있으면 그 문서로 라우팅한다.

## 출력과 중단

확인된 Git 규칙과 근거를 출력한다. 명시 정책이 없으면 에이전트가 커밋·push·PR을 수행한다고 가정하지 않는다.
