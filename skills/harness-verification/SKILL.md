# Harness Verification

`../../standard_v0.md`의 `4. 검증 및 QA`를 기준으로 한다.

## 수행

- 패키지·빌드 설정, CI, 테스트 파일, 기존 문서에서 실제 명령을 확인한다.
- 변경 유형별 필수 검증과 수동 QA가 존재하는 경우에만 반영한다.
- 수행할 수 없는 검증의 보고 방식을 포함한다.

## 출력과 중단

명령, 근거 경로, 적용 조건, 미확인 검증을 명시한다. 실행해 보지 않았거나 존재하지 않는 명령을 통과 기준으로 쓰지 않는다.
