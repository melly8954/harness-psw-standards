# Harness Secrets

`../../standard_v0.md`의 `8. 환경 변수 및 시크릿`을 기준으로 한다. 이 규칙은 전체 하네스 과정에도 적용한다.

## 수행

- `.env.example`, ignore 규칙, 설정 문서, 시크릿 관리 진입점만 확인한다.
- 변수의 이름·목적은 예제로 정리할 수 있으나 실제 값은 읽어 출력하거나 기록하지 않는다.
- 배포 환경이나 시크릿 저장소의 변경 책임을 확인한다.

## 출력과 중단

안전 규칙, 관련 파일 경로, 확인 필요 사항을 출력한다. 실제 시크릿이나 운영 값을 추정·노출·변경하지 않는다.
