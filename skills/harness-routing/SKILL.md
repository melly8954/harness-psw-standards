# Harness Routing

`../../standard_v0.md`의 `1. 문서 라우팅`을 기준으로 한다.

## 수행

- 문서 색인과 실제 문서 영역을 확인한다.
- 요구사항, API, 아키텍처, 데이터, 구현, 디자인, 검증, 운영 등 존재하는 영역만 지도에 넣는다.
- 문서 규모가 큰 경우 루트와 하위 라우터의 책임을 정한다.

## 출력과 중단

작업 목적·대상·영향 범위별 진입점, 근거 경로, 생략된 영역을 출력한다. 존재하지 않는 경로나 문서를 제안하지 않으며, 코드와 문서 충돌은 확인 필요로 남긴다.
