# Harness Scope

프로젝트 지시서에는 에이전트가 현재 레포의 책임 범위를 빠르게 이해할 수 있도록 프로젝트의 목적과 경계를 정의한다.

## 포함할 수 있는 내용

- 이 레포가 무엇을 하는지
- 주요 책임 영역
- 이 레포가 담당하지 않는 범위
- 다른 레포·서비스·시스템과의 책임 경계
- 작업 시 특히 주의해야 하는 프로젝트 특성

세부 기능 목록이나 전체 요구사항을 이 영역에 복사하지 않는다. 상세 내용은 관련 문서로 라우팅한다.

## 출력과 중단

프로젝트 사실 목록과 README·아키텍처·모듈 문서의 근거를 사용해 포함 여부, 초안, 근거 경로, 확인 필요 사항을 낸다. 책임 경계가 문서마다 충돌하면 정답을 선택하지 말고 차이를 보고한다.
