# Harness Scope

`../../standard_v0.md`의 `0. 프로젝트 개요와 범위`를 기준으로 한다.

## 입력

프로젝트 사실 목록과 README·아키텍처·모듈 문서의 근거를 사용한다.

## 수행

- 이 레포의 목적과 주요 책임을 짧게 정리한다.
- 담당하지 않는 범위와 외부 서비스·레포와의 경계를 확인한다.
- 작업 시 특히 주의할 특성만 남긴다.

## 출력과 중단

포함 여부, 초안, 근거 경로, 확인 필요 사항을 낸다. 책임 경계가 문서마다 충돌하면 정답을 선택하지 말고 차이를 보고한다.
