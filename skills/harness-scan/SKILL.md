# Harness Scan

`../../standard_v0.md`의 작성 원칙을 읽는다. 이 단계는 최종 지시서가 아닌 사실 목록을 만든다.

## 조사

- 프로젝트 목적, 모듈 경계, 최상위 문서를 확인한다.
- 기존 `AGENTS.md`, `CLAUDE.md`, README, 문서 색인과 하위 지시서를 찾는다.
- 빌드·테스트·린트·실행 명령과 CI 설정을 실제 파일에서 확인한다.
- Git 상태, 브랜치·PR 안내, 환경 변수 예시와 시크릿 관련 파일을 확인한다.

## 출력

각 사실에 근거 경로를 붙여 다음을 정리한다: 프로젝트 범위, 문서 지도, 기술·모듈 규칙, 검증 명령, 운영 경계, 협업·Git 정책, 시크릿 취급. 알 수 없는 항목은 `확인 필요`로 남긴다.

## 금지

관례만으로 명령·문서·정책을 추정하거나, 조사 과정에서 시크릿 값을 출력하지 않는다.
