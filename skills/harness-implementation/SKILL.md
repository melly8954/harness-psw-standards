# Harness Implementation

`../../standard_v0.md`의 `3. 구현 규칙`을 기준으로 한다.

## 수행

- 실제 기술 스택, 모듈 경계, 코드 소유권, 기존 컨벤션을 확인한다.
- 세부 규칙 전문을 복사하지 않고, 재사용·의존성·새 패턴 도입 기준과 문서 진입점만 정리한다.
- 백엔드·프런트엔드·디자인 규칙은 대상 프로젝트에 실제 문서가 있을 때만 라우팅한다.

## 출력과 중단

구현 원칙 초안, 참조 문서, 생략 영역을 출력한다. 확인되지 않은 기술 규칙을 새로 정의하지 않는다.
