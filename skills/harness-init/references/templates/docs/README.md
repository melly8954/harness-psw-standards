# 프로젝트 문서 지도

이 문서는 프로젝트 문서의 책임과 진입점을 안내한다. 모든 문서를 미리 읽지 않고, 현재 작업에 필요한 영역만 확인한다.

| 문서 영역 | 소유 내용 | 주요 진입점 |
| --- | --- | --- |
| `prd/` | 요구사항, 사용자 시나리오, 완료 조건 | [문서] |
| `architecture/` | 시스템 구성, 데이터 흐름, 외부 연동 | [문서] |
| `api/` | API와 이벤트 계약 | [문서] |
| `erd/` | 데이터 모델과 관계 | [문서] |
| `conventions/` | 구현, 협업, Git 관례 | [문서] |
| `testing/` | 테스트와 QA 절차 | [문서] |
| `operations/` | 실행, 배포, 운영 경계 | [문서] |
| `security/` | 시크릿, 권한, 보안 경계 | [문서] |
| `decisions/` | 결정 기록과 미결 사항 | [문서] |

프로젝트에 없는 영역은 행과 링크를 제거한다. 실제 경로와 소유 문서로 교체한다.
