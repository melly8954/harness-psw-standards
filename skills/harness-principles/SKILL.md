# Harness Principles

`../../standard_v0.md`의 `2. 공통 작업 원칙`을 기준으로 한다. 이 원칙은 이후 모든 하네스 단계에도 적용한다.

## 수행

- 기존 구조·의도 확인, 요청 범위 준수, 영향 범위 확인 기준을 정리한다.
- 프로젝트에 실제로 존재하는 우선순위·정합성 규칙만 반영한다.
- 현재 요청과 별개로 발견한 문제를 분리하는 방식을 명시한다.

## 출력과 중단

공통 원칙 초안과 근거를 출력한다. 충돌 우선순위가 확인되지 않으면 임의의 우선순위를 만들지 않는다.
