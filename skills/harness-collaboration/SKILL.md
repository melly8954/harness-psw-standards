# Harness Collaboration

여러 사람 또는 여러 에이전트가 같은 프로젝트에서 작업할 때 기존 변경을 훼손하거나 불필요한 충돌을 만들지 않도록 기본 원칙을 정의한다. 이 규칙은 전체 하네스 과정에도 적용한다.

## 포함할 수 있는 원칙

- 요청받지 않은 기존 변경을 임의로 되돌리지 않는다.
- 현재 작업과 관련 없는 파일을 불필요하게 수정하지 않는다.
- 대규모 자동 포맷이나 일괄 변경으로 불필요한 diff를 만들지 않는다.
- 기존 작업과 충돌 가능성이 있으면 변경 범위를 확인한다.
- 다른 변경의 의도를 알 수 없는 경우 임의로 정리하거나 덮어쓰지 않는다.
- 동시에 수정될 가능성이 높은 파일이나 공통 영역을 변경할 때 영향 범위를 확인한다.
- 작업 중 발견한 다른 사람 또는 에이전트의 변경을 현재 요청과 구분해 다룬다.

## 출력과 중단

협업 규칙 초안과 근거를 출력한다. 다른 변경의 의도가 불명확하면 정리·되돌리기를 지시하지 않는다.
