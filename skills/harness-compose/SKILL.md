# Harness Compose

승인된 문서 계획, 검토된 초안, 근거, 사용자 결정 사항을 받아 계획된 모든 파일을 반영한다. 승인되지 않은 파일을 새로 만들거나 갱신하지 않는다.

## 조립 원칙

- 계획에서 `생성` 또는 `갱신`된 파일만 반영한다.
- 루트 지시서는 경량 라우터로 유지하고, 상세 정보는 `docs/*`의 소유 문서에 둔다.
- 모든 경로, 문서, 명령, 정책은 조사 근거와 대조한다.
- 기존 문서를 갱신할 때는 승인된 범위만 최소 변경한다.
- 문서와 코드의 충돌, 미확인 정책, 수행하지 못한 검증은 숨기지 않고 별도로 보고한다.

## 확인과 인터뷰

반영 전 파일 목록, 각 파일의 처리 방식, 초안, 근거, 사용자 결정 사항을 대조한다. 근거 없는 문장, 존재하지 않는 경로·명령, 다른 문서와 충돌하는 규칙은 반영하지 않는다.

## 반영

승인 후에만 대상 `AGENTS.md`, `CLAUDE.md`, `docs/*`를 생성·갱신한다. 최종 결과에는 반영·생략한 파일, 근거, 검증 결과를 함께 보고한다.
