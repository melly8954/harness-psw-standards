# Harness Compose

`../../standard_v0.md` 전체를 읽어 섹션을 조립한다.

## 입력

프로젝트 사실 목록과 각 섹션의 포함·생략 결정, 초안, 근거, 확인 필요 사항을 받는다.

## 수행

- 필요한 섹션만 선택해 중복 없이 조립한다.
- 문서·경로·명령·정책마다 조사 근거가 있는지 대조한다.
- 문서와 코드의 충돌, 미확인 정책, 수행하지 못한 검증을 별도 보고한다.

## 출력과 반영

먼저 검토 가능한 초안을 출력한다. 사용자가 명시적으로 반영을 요청한 경우에만 대상 `AGENTS.md`, `CLAUDE.md` 또는 하위 지시서를 수정한다. 최종 결과에는 반영 파일과 검증 결과를 함께 보고한다.
